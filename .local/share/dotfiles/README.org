** Installation
To install:
#+begin_src sh
  wget -nc -P /tmp https://github.com/benjamin-james/dotfiles/raw/refs/heads/bare/bin/gcfg
  chmod u+x /tmp/gcfg
  /tmp/gcfg bootstrap
#+end_src

*** shell
By default no =~/.bashrc=, =~/.bash_profile=, =~/.profile=, etc are provided to be able to plug-in.
To add, in
=~/.profile=, or =~/.bash_profile= if it exists,
#+begin_src sh
  [ -r "$HOME/.config/shell/login.sh" ] && . "$HOME/.config/shell/login.sh"
#+end_src

and for rc, whether =~/.bashrc=, =~/.kshrc=, =~/.zshrc=:
#+begin_src sh
  [ -r "$HOME/.config/shell/interactive.sh" ] && . "$HOME/.config/shell/interactive.sh"
#+end_src

*** lisp

  wget -nc -P /tmp http://beta.quicklisp.org/quicklisp.lisp
  sbcl --no-sysinit --no-userinit --load /tmp/quicklisp.lisp \
       --eval '(quicklisp-quickstart:install :path "~/.local/share/quicklisp")' \
       --eval '(ql:add-to-init-file)' \
       --quit
  ### stumpwm

       --eval '(ql:quickload "swank")'
