* dotfiles
My dotfiles repository

** Installation
To install:
#+begin_src sh
  wget -nc -P /tmp https://github.com/benjamin-james/dotfiles/raw/refs/heads/bare/bin/gcfg
  chmod u+x /tmp/gcfg
  /tmp/gcfg bootstrap
#+end_src

*** shell
By default no =~/.bashrc=, =~/.bash_profile=, =~/.profile=, etc are provided to be able to plug-in.
To add, in
=~/.profile=, or =~/.bash_profile= if it exists,
#+begin_src sh
  [ -r "$HOME/.config/shell/login.sh" ] && . "$HOME/.config/shell/login.sh"
#+end_src

and for rc, whether =~/.bashrc=, =~/.kshrc=, =~/.zshrc=:
#+begin_src sh
  [ -r "$HOME/.config/shell/interactive.sh" ] && . "$HOME/.config/shell/interactive.sh"
#+end_src

** Identity
Personal identity (name, email, GPG key, SSH user, etc.) is committed
as real values in config files so a fresh clone works with zero setup.

To use these dotfiles as your own:
1. Copy =identity.defaults.sh= to =identity.local.sh= (gitignored)
2. Edit the values in =identity.local.sh=
3. Run =gcfg render=

=gcfg render= does in-place substitution using a registry
(=~/.local/share/dotfiles/render-registry=) that maps identity
variables to the files where they appear. Longer values are replaced
first per file to avoid substring collisions (e.g.
=benjames@csail.mit.edu= before =benjames=). Rendered files are
auto-marked =skip-worktree= so =git status= stays clean; =gcfg pull=
temporarily reveals them for update, then re-renders.

=gcfg check= (wired as a pre-commit hook) verifies every default value
still exists in its registered files and catches drift when a value
changes in one place but not the other.
